Editor

Changes are saved straight to your GitHub repository. To sign in you need a fine-grained personal access token that can only edit this one repository.

The token is then kept in this browser's storage, which every site under the same github.io address can read. Only use this on your own device and if you don't publish other sites with third-party scripts under this GitHub account.

How to create the token (2 minutes)
  1. Open GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name: City Walks editor. Expiration: 30 days or less.
  3. Repository access: Only select repositories → this repository.
  4. Repository permissions → Contents: Read and write. Nothing else.
  5. Generate, copy and paste it above. GitHub only shows it once; just make a new one when it expires.

The token never leaves your browser except to talk to api.github.com. This editor can only change cities.json and walk-*.json, never the app's code.

The list (cities, walk order, titles) is stored in cities.json. After each save GitHub rebuilds the walk data (a few minutes). Open the app › Build status ›
